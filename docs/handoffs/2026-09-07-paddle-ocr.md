# 交接记录：Paddle 云端 OCR 接入（2026-09-07）

任务来源：用户直接分配（"OCR 可以用 paddle 的，每天有 20000 额度"），依据 AGENTS.md "用户的新明确指令优先于工作约定" 执行。**本任务改变了数据外发政策**（新增可选的截图云端识别通道），按约定在此记录影响，供规划助手复核。

## 实现方式

- 新增 `desktop/src/main/paddle-ocr.ts`：提交截图 → 轮询任务 → 下载 JSONL → 递归收集 `rec_texts`（对 Paddle 流水线版本间字段差异做了防御性匹配，已用真实 API 探针确认 PP-OCRv6 响应结构）。
- 新增 `desktop/src/main/ocr-config.ts`：本地 / Paddle 双提供者路由，配置存 `helm-ocr-config.json`（userData），Token 支持环境变量 `HELM_PADDLE_TOKEN` / `PADDLE_OCR_TOKEN` 兜底。
- 设置界面新增"OCR 方式"区：**默认本地 OCR（数据不出本机）；Paddle 为默认关闭的可选项**，启用时界面明确声明"每张屏幕截图会上传到 paddleocr.aistudio-app.com"。
- Token 未提交到仓库；仅存在于用户本机 userData 配置。

## 外发政策影响（重点）

| 状态 | 截图图像 | OCR 文本 |
| --- | --- | --- |
| 默认（本地 OCR） | 不出本机 | 不出本机 |
| 启用 Paddle 后 | **每张上传至 Paddle 服务** | 识别文本回传本机，后续报告链路不变 |

启用动作为设置里的显式切换 + 界面声明，未做逐张确认（逐张确认会打断持续感知的产品形态）；此取舍请规划助手复核。

## 已知取舍与待决策

- OCR 时长：云端任务约 3~10 秒，感知 tick 会相应变慢（采集间隔仍受最小 15 秒保护）。
