## 需要优先处理的语义差距

1. **实际外发内容**：`desktop/src/main/ai/report.ts` 向配置的 `/chat/completions` 服务发送 OCR 文本片段。错误信息中的 API Key 脱敏，不等于输入内容脱敏。文档现已纠正；应用内说明和外发前控制尚待实现。
2. **没有可用历史对比输入**：当前提示词要求“只讲变化”，但报告调用未接入历史基线与目标。生成“比平时更……”没有可靠依据，需要修改输入与输出约束。
3. **覆盖与截断**：报告取当日现存 OCR，过滤空文本后使用前 120 条，每条约 400 字符。早期数据可能已清理，后续数据也可能因上限遗漏；无法代表完整一天。去重快照数也不能直接换算持续时间或时间占比。
4. **证据与纠正断开**：报告是生成文本，尚无逐条发现到来源的稳定引用、用户纠正记录及重新分析机制。源记录删除后，还需要诚实标记证据不可用。
5. **清理保证有限**：清理不是独立严格定时器；暂停、重复采集或错误可能延迟处理。文件删除失败也不能当作已安全销毁。保留策略的改变需要明确设计，不应为日报覆盖默默延长保留。
